Visão Geral do Projeto

O AppCuidaAmor é uma plataforma digital completa desenvolvida para a empresa Cuida e Amor Home Care, conectando as famílias dos pacientes ao serviço de assistência domiciliar de forma intuitiva, segura e profissional.


A solução entregue compreende um aplicativo mobile nativo (Android e iOS via Capacitor), um portal web responsivo e toda a infraestrutura de backend e banco de dados integrada ao sistema ERP legado SoftCare, já em operação na empresa.

Termos e Condições Gerais

Propriedade intelectual
Todo o código-fonte desenvolvido no escopo deste projeto é propriedade exclusiva do cliente (Cuida e Amor Home Care) após a quitação integral do valor contratado.

Garantia pós-entrega
Garantia de 60 dias para correção de bugs funcionais identificados após a entrega final, sem custo adicional. Novas funcionalidades são tratadas como novos contratos.

Comunicação e aprovações
O cliente se compromete a fornecer feedback sobre cada fase em até 5 dias úteis. Atrasos superiores a 10 dias úteis podem impactar o cronograma de entrega.

Banco de dados legado
O sistema integra diretamente ao banco SQL Server do ERP SoftCare. Qualquer alteração na estrutura do banco pelo time do ERP pode requerer ajustes no app, a serem tratados separadamente.

Confidencialidade
Todas as informações, credenciais, dados de clientes e estrutura do banco de dados trocados durante o desenvolvimento são tratados com total confidencialidade.

Validade desta proposta
Esta proposta tem validade de 30 dias corridos a partir da data de emissão. Após este prazo, os valores podem ser revisados conforme variações do mercado.
